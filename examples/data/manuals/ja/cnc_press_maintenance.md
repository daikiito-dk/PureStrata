# 安全上の注意

警告: 点検作業の前に必ず主電源を切り、切り忘れ防止ラベルを掲示すること。ブレーキユニット内部は電源遮断後も10分間充電された状態が続く。

注意: ボルトの締付けは指定トルク管理表に従うこと。過剰締付けは滑り荷重の低下を招く。

# 週次点検手順

1. 潤滑ユニットの油面を確認し、下限ライン以下の場合はオイルを補給する。
2. ボールネジの手動送り時の異音を確認する。
3. ブレーキテストを実施し、停止時間が0.8秒以内であることを確認する。
4. 型クランプボルトの増し締めをトルクレンチで行う。

# 故障時の対応

## 下死点オーバーシュート

スライドが下死点を0.1 mm以上オーバーシュートする場合は、ブレーキユニット（品番 BK-2207）の摩耗またはゲートドライバの劣化を疑う。まずブレーキ停止時間を測定し、規定値の0.8秒を超えている場合はユニットを交換する。

注意: ブレーキユニット交換後は、必ずブレーキテストを3回実施して停止時間を記録すること。
