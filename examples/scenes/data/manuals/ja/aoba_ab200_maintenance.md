# 安全上の注意

警告: 点検作業の前に必ず主電源を切り、切替スイッチをロック位置にして掛札を掲示すること。インバータ内部は電源遮断後も5分間充電された状態が続く。

注意: インペラの回転方向は矢印ステッカーの方向と一致を確認すること。逆回転で起動すると風量が低下し、モータが過熱する。

# 仕様の概要

AB-200は風量 40 m3/min、静圧 1.2 kPa、回転数 1750 rpm の軸流ブロワユニットである。駆動は 5.5 kW 三相誘導モータとインバータ INV-5500 で行い、動力伝達はVベルト BLT-A45 による。軸受は複列深溝玉軸受 BR-6208 を2個使用し、シャフトシール SL-0325 で防塵する。

# 週次点検手順

1. 運転音を聴き、軸受部で規定を超える異音がないか確認する。
2. 振動計で軸受ハウジングの振動を測定し、4.5 mm/s RMS以下であることを確認する。
3. Vベルトのたわみ量を指圧法で確認し、10 mm前後であることを確認する。
4. インバータ表示部の積算運転時間を保全台帳に記録する。
5. 吸込フィルタの目詰まりインジケータが黄色の場合は清掃する。

# 定期保全手順（軸受給脂）

1. 主電源を切り、放電待ち時間5分を確実にとる。
2. 給脂口のキャップを外し、グリースガンで BR-6208 に規定量の20 gを注入する。
3. 注入後、キャップを確実に締め、注入日を給脂ラベルに記入する。
4. 手動でシャフトを1回転させ、グリースの偏在をならす。

# 故障時の対応

## 軸受部の異音と振動

運転中に軸受部からカラカラという異音がし、振動が 6 mm/s RMS を超える場合は、軸受 BR-6208 の転動面の剥離または給脂切れを疑う。給脂履歴を確認し、給脂で改善しない場合は軸受を交換する。交換時はベアリングカバー（品番 AB-200-CVR）を取り外し、軸受プーラで抜き取る。

注意: 軸受交換後は必ず振動測定を行い、4.5 mm/s RMS以下を確認してから本運転に戻すこと。

## 風量低下

風量が定格の80 %を下回る場合は、Vベルト BLT-A45 のすべりまたは吸込フィルタの目詰まりを疑う。ベルトたわみが15 mmを超える場合は張り調整を行う。調整後は2週間後に再確認し、再発する場合はベルト一式を交換する。

## インバータ過電流停止

インバータ INV-5500 が過電流で停止を繰り返すときは、ベルトの過締めによる負荷増加か、モータの絶縁劣化を疑う。モータ絶縁抵抗を測定し、1 MΩ未満の場合はモータを交換する。
