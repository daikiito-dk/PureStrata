Why this existsなぜ作ったのか

Manufacturing is where LLMs struggle most: CAD drawings, dense maintenance manuals, and failure knowledge locked in spreadsheets. Japanese factories in particular hold decades of primary data that never reaches the open web.製造業はLLMが最も苦手とする領域です。CAD図面、高密度な保全マニュアル、そしてスプレッドシートに閉じ込められた不具合ナレッジ。特に日本の工場には、Web上に存在しない一次データが蓄積されています。

LLMs are weak on manufacturing dataLLMは製造業データが苦手

CAD files, dense spec sheets, and failure logs are exactly the data that never made it into pretraining corpora.CADファイル・高密度な仕様書・故障記録こそ、事前学習データに入り込まなかったデータです。

Failure knowledge is the missing stratum不具合ナレッジという欠けていた地層

Most RAG retrieves manual text. Factory troubleshooting runs on symptom → cause → countermeasure records. PureStrata treats them as first-class structured data.多くのRAGはマニュアル本文のみを検索します。工場のトラブルシューティングは「現象→原因→対策」の記録で回っています。PureStrataはそれを第一級の構造化データとして扱います。

Provenance is non-negotiable出所証明は譲れない条件

Every record keeps its source file and locator, so any answer can be audited back to the drawing, section, or row it came from.すべてのレコードが元ファイルと位置を保持し、回答がどの図面・セクション・行から来たか監査できます。

No lock-inロックインなし

The corpus is plain JSONL you own. Zero required dependencies. Runs locally, air-gap friendly, with Japanese search built in.コーパスは自分のもののプレーンなJSONL。必須依存はゼロ。ローカル実行・エアギップ対応で、日本語検索も組み込み済みです。

Three record families, first-class data第一級データとして扱う3つのレコード族

One schema (purestrata/v1) covers the documents a factory actually troubleshoots with. Every record carries provenance: source file plus locator.工場の実務で使う文書を1つのスキーマ（purestrata/v1）で扱います。すべてのレコードに「元ファイル＋位置」の出所情報が付きます。

Quickstartクイックスタート

Install, ingest, query like an LLM would, then export training data from the same corpus.インストールして取り込み、LLMと同じ形式で検索し、同じコーパスから学習データを書き出します。

# install (Python 3.10+)
uv add purestrata            # or: pip install purestrata

# ingest drawings, spec sheets, and failure knowledge into a corpus
purestrata ingest-manual manual.md --out corpus/
purestrata ingest-dxf drawing.dxf --out corpus/
purestrata ingest-step model.step --out corpus/
purestrata ingest-failures failures.csv --out corpus/

# query exactly the way an LLM would
purestrata search "spindle vibration" --corpus corpus/
purestrata call search_drawings '{"min_diameter": 24, "fit": "H7"}' --corpus corpus/

# export fine-tuning datasets from the same corpus
purestrata export chat       --corpus corpus/ --out dataset_chat.jsonl
purestrata export tool_trace --corpus corpus/ --out dataset_tools.jsonl
purestrata export cot        --corpus corpus/ --out dataset_cot.jsonl

Works with any LLMどのLLMとも連携

No model is special. Register the MCP server, or pass the bundled schemas to an OpenAI-compatible API, or just use Python.特定モデルへの依存はありません。MCPサーバーを登録するか、OpenAI互換APIにスキーマを渡すか、Pythonで直接使うか。

Python

Library APIライブラリAPI

import purestrata as ps

chunks = ps.ingest_manual("manual.md")
chunks += ps.ingest_failures("failures.csv")
ps.write_chunks(chunks, "corpus/", "my_doc")

executor = ps.ToolExecutor(ps.Corpus.load("corpus/"))
hits = executor.execute(
    "search_failure_cases",
    {"query": "spindle vibration", "top_k": 3},
)
